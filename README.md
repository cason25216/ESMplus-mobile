# ESM+ Seller Pocket

面向 Gmarket 商家的移动端 MVP 交互原型。所有数据均为模拟，不连接真实商家后台。

直接打开 `index.html`，无需安装或构建。支持手机和桌面浏览器。

页头支持中文、English、한국어三语即时切换，并记住语言偏好。切换时保留当前价格方案和报名结果。导航包含经营看板、活动机会、活动报告三个入口，报告内可切换日报和整期复盘。报名页采用紧凑卡片，规则默认折叠。

## 体验路径

经营看板 → 活动机会 → 调整活动售价、SD、SV → 选择商品 → 确认报名 → 查看已报名。

活动日报支持切换日期；活动复盘支持导出文本报告。报名结果保存于当前浏览器 localStorage，清除站点数据可重置。

日报与复盘使用不同历史活动，新报名活动尚未开场。优惠叠加公式为原型演示假设，正式上线需要对接平台规则。

## GitHub Pages

将本目录上传至公开 GitHub 仓库。在 Settings → Pages 中选择 Deploy from a branch，选择 main 分支和 / (root)，保存。发布完成后访问 `https://用户名.github.io/仓库名/`。

无依赖、无密钥、无真实商家数据。外部字体不可用时自动使用系统字体。
